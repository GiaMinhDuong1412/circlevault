Đặt tên để bạn nhận ra thiết bị này trong danh sách trên máy tính.

🔒 Thiết bị này chưa được phép

CircleVault chỉ mở cho thiết bị bạn đã ghép. Trên máy tính: tab Lưu Trữ → Mang theo điện thoại → Thêm thiết bị, rồi dùng điện thoại này quét mã QR.

📱 Có app CircleVault cho Android
Chọn bộ nhớ máy/thẻ nhớ ngay trong app, nghe và xem offline, xóa trong app. Bấm để tải về rồi cài.

Chọn nhạc hoặc phim, bấm Tải về khi máy tính còn bật. Tải xong thì tắt máy tính, điện thoại vẫn nghe và xem được, không cần mạng.

📁 Chọn nơi lưu: bộ nhớ máy hay thẻ nhớ
  1. Mở Chrome → nút ⋮ (góc trên bên phải) → Cài đặt → Tải xuống.
  2. Vị trí tải xuống: chọn Bộ nhớ trong hoặc Thẻ SD. Mục này chỉ hiện khi điện thoại có lắp thẻ nhớ.
  3. Muốn chọn mỗi lần tải: bật Hỏi vị trí tải xuống.

Samsung Internet: ≡ → Cài đặt → Trang web và tải xuống → Lưu tệp đã tải tại.

Nếu Chrome hỏi có giữ file tải từ mạng nhà (http) không, chọn Giữ lại: file đi thẳng từ máy tính của bạn.

Thẻ nhớ dưới 32 GB (FAT32) không chứa được một file lớn hơn 4 GB. Gặp file như vậy, app sẽ nhắc tải từng bài hoặc lưu vào bộ nhớ trong.

▶ Nghe, xem và xóa trên điện thoại

Gói playlist (.zip)

  1. Mở app Files (Files by Google), hoặc File của bạn trên Samsung → Tải xuống.
  2. Bấm vào file CircleVault - …zip → Giải nén. Bạn sẽ có một thư mục cùng tên playlist. File .zip xóa được ngay sau đó.
  3. Nghe: mở thư mục, bấm file .m3u8 bằng VLC (miễn phí trên CH Play) để nghe đúng thứ tự. App nhạc của máy cũng tự thấy các bài.

Phim

Bấm file .mp4 trong app Files, hoặc mở bằng Thư viện ảnh hay VLC.

Xóa để tải đợt mới

Trong app Files, giữ tay lên thư mục playlist hay file phim → Xóa. Nhớ dọn cả Thùng rác của app Files để lấy lại dung lượng.
